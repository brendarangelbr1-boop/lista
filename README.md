# Quicklist

Aplicação de lista de compras desenvolvida para facilitar a organização dos itens do dia a dia, com uma interface intuitiva e responsiva.

## Demonstração

[Visualizar projeto](COLE_AQUI_O_LINK_DO_SEU_SITE)

![Preview do Quicklist](./💻%20(1).png)

## Funcionalidades

- Adicionar itens à lista de compras.
- Marcar itens como concluídos.
- Remover itens da lista.
- Exibir mensagens de feedback ao usuário.
- Interface responsiva para desktop e dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
